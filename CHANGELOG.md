# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.1.0] - 2026-07-16

### Added
- OpenRouter integration for fully free AI telemetry insights.
- `CONTRIBUTING.md` guidelines for open-source developers.
- `ARCHITECTURE.md` high-level documentation.
- Issue and Pull Request templates for standardizing contributions.

### Changed
- Replaced Google Gemini with OpenRouter (Gemma 4 31B) for AI-driven recommendations.
- Updated Dashboard UI to consume dynamic JSON recommendations instead of static math heuristics.

## [1.0.0] - 2026-07-10

### Added
- Initial release of ContriTrack.
- GitHub OAuth integration for repository syncing.
- Supabase PostgreSQL schema for tracking Tasks, Workspaces, and Analytics.
- Firebase Authentication workflow.
- Playwright end-to-end testing setup.
